# Para mi amor ♡

Protótipo de um jogo-presente em HTML, CSS e JavaScript, feito para funcionar no navegador de computador e celular.

## O que há nesta versão

- Tela inicial em pixel art com o pôr do sol enviado pela autora.
- Botões em sprite retirados da referência visual enviada: START, LEVEL, SETTING, OPTIONS e QUIT.
- Movimento parallax: o cenário acompanha o mouse no computador e o toque no celular.
- Configuração para desligar o movimento da tela.
- História com escolhas, pistas, minigame de ritmo, minigame de voo e finais diferentes.

## Arquivos

- `index.html`: página principal.
- `style.css`: visual e responsividade.
- `game.js`: lógica da história e do menu.
- `assets/`: fundo de pixel art e sprites dos botões.

## Testar localmente

Abra `index.html` em um navegador moderno. O jogo não usa bibliotecas externas.

## Publicar no GitHub Pages

1. Envie os arquivos `index.html`, `style.css`, `game.js`, `README.md` e a pasta `assets/` para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`, depois salve.
5. Aguarde alguns minutos para o site ser publicado.

O menu é um protótipo inicial; a história ainda pode ser ampliada e personalizada antes de entregar o presente.
