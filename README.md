# para mi amor — protótipo 0.2

Um protótipo jogável de visual novel/minigames para um presente de namoro, em HTML, CSS e JavaScript puro.

## Como testar
- Abra `index.html` no navegador.
- Funciona sem instalação e sem internet.
- O minigame de voo aceita toque/clique e barra de espaço.

## Como publicar no GitHub Pages
1. Crie um repositório público no GitHub, por exemplo `para-mi-amor`.
2. Envie `index.html`, `style.css` e `game.js` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação; o GitHub mostrará o endereço do jogo nessa mesma página.

## Personalização recomendada
- Troque a carta final em `game.js` por uma mensagem escrita com suas próprias palavras.
- Adicione sprites próprios em `assets/` e substitua os emojis no HTML/JS.
- Para Jão e músicas relacionadas a QSMP, prefira links oficiais ou arquivos que você tenha permissão para usar; o protótipo não embute música protegida por direitos autorais.
- Este protótipo é curto e demonstra mecânicas; a versão de 40+ minutos deve ganhar mais capítulos, cenas, diálogos e variações de finais.

## Planejamento de produção (versão completa)
1. **Pré-produção:** definir a revelação central, o tom emocional e a carta verdadeira.
2. **Capítulo 1:** introdução, exploração de quarto, 3 pistas e primeira lembrança.
3. **Capítulo 2:** minigame de corações em sincronia, diálogo de consequência e cena pessoal.
4. **Capítulo 3:** minigame Flappy personalizado com obstáculos temáticos e uma pista desbloqueável.
5. **Capítulo 4:** puzzle de símbolos com pistas encontradas em cenas anteriores.
6. **Capítulo 5:** escolhas que mudam diálogos, acesso a cenas e final.
7. **Capítulo 6:** revelação que ressignifica as pistas anteriores e declaração de amor.
8. **Polimento:** sprites pixel art, som ambiente, acessibilidade, salvamento de progresso e testes em celular.
9. **Publicação:** GitHub Pages e teste do link em modo anônimo/celular.

## Observações
- O código é intencionalmente simples para ser fácil de editar.
- Os nomes de personagens e referências são homenagens de fã; não use artes ou músicas de terceiros sem permissão.
